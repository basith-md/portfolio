Corticomuscular Coherence Analysis on Leg Movements

This repository contains the MATLAB implementation and research findings for a final year project analyzing the functional connection between the human brain and muscles during various leg movements.

Tabular Autopilot

Tabular Autopilot is a tool designed to automate the process of building machine learning models for tabular data. It simplifies the workflow by handling data preprocessing, feature engineering, model selection, and hyperparameter tuning.

Python Machine Learning Automation Tabular Data

Bookworm

A robot arm that turns real book pages with a pencil eraser, then reads them aloud or scans them into a searchable PDF without damaging the book. I built the calibration workshop, touch-based book model and the flip path that adapts to the book's position.

Winner · Viam "Code that Moves" Hackathon
Python Robotics Viam Computer Vision OCR

Traffic Accidents Analysis

This repository contains an analytical and predictive study of road traffic accidents in England, Scotland, and Wales using official UK traffic and accident datasets spanning 2005–2014. The project investigates patterns, trends, and predictive factors related to accident severity, casualties, police response, and time-of-day accident frequency.

R Random Forest Ridge Regression Feature Engineering

Water Connect

An off-grid mesh-network messaging simulator with text and low-bitrate voice that hops across phones with no internet. I built Water Connect and the Water AI gateway, which lets a phone ask questions over the mesh and get answers relayed back through an internet-connected node.

TypeScript Python React Mesh Networking LLM Gateway

Sweeesh

Verifiable resumes: each claim is signed and checked up a chain of trust (person → institution → register → root), so employers can verify it without contacting anyone. I built the verifiable-credential demo and its deployment.

Winner · Trust in the Hiring Funnel track, NYU
JavaScript Python Verifiable Credentials Cryptography

Robologue

A procedural-memory system for AI agents that remembers unresolved mistakes across a long task and learns which evidence to check before marking a step done. Evaluated on real procedural-activity recordings, with memory stored in MongoDB Atlas.

Python AI Agents MongoDB Atlas Evaluation
